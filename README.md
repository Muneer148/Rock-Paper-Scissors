# Rock Paper Scissors Game

Academic Python GUI project implementing a Rock Paper Scissors game with Tkinter.

## Features
- Tkinter graphical interface
- User choice buttons
- Random computer choice
- Conditional game logic
- Score / feedback interface elements

## Project status
Team academic project completed as part of undergraduate coursework at St. Martin's Engineering College.
