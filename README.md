# Rock Paper Scissors

A simple Python/Tkinter graphical Rock Paper Scissors game developed as an undergraduate academic team project.

> **Project type:** Team academic project

## Features

- Tkinter graphical user interface
- Rock, Paper, and Scissors choice buttons
- Random computer selection
- Win / loss / draw logic
- Player, computer, and draw score tracking
- Reset button
- No external runtime packages required

## Project structure

```text
Rock-Paper-Scissors/
├── README.md
└── rock_paper_scissors.py
```

## Run

Python 3.x with Tkinter.

```bash
python rock_paper_scissors.py
```

## Game logic

```text
Rock     beats Scissors
Scissors beats Paper
Paper    beats Rock
Same move = Draw
```

The original project was developed as part of undergraduate coursework at **St. Martin's Engineering College**.
